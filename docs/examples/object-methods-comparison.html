🏆 ASF vs JavaScript

Object Methods Comparison

Array Processing

▼

ASF Native Objects

ASF arrays are native VBA arrays enhanced with methods. No conversion needed - direct manipulation of data. 
let numbers = [1, 2, 3, 4, 5];

// Native VBA Collection methods
let doubled = numbers.map(fun(n) { 
    return n * 2; 
});

let filtered = numbers.filter(fun(n) { 
    return n > 3; 
});

let sum = numbers.reduce(fun(acc, n) { 
    return acc + n; 
}, 0);

// Works directly with VBA objects
print(doubled);   // [2, 4, 6, 8, 10]
print(filtered); // [4, 5]
print(sum);      // 15
ASF Advantage: Direct manipulation of VBA Collections. No overhead, no conversion. Native performance with modern syntax.

JS Array Conversion

JavaScript requires converting VBA objects to JS arrays first, then back to VBA. Performance overhead and type conversion issues. 
// Must convert VBA Collection to Array
let vbaCollection = getVBAData();
let jsArray = Array.from(vbaCollection);

// Process in JavaScript
let doubled = jsArray.map(n => n * 2);
let filtered = jsArray.filter(n => n > 3);
let sum = jsArray.reduce((acc, n) => acc + n, 0);

// Convert back to VBA Collection
let doubledVBA = convertToVBA(doubled);
let filteredVBA = convertToVBA(filtered);

// Performance penalty from conversions
console.log(doubled);   // [2, 4, 6, 8, 10]
console.log(filtered); // [4, 5]
console.log(sum);      // 15
JavaScript Limitation: Conversion overhead between VBA and JS types. Memory usage increase. Type safety issues at boundaries.

Object Property Access

▼

ASF VBA Integration

ASF objects are native VBA Arrays wrapped in a class with methods. Direct object access and manipulation. 
let employees = [
    {name: 'Alice', salary: 75000, dept: 'Engineering'},
    {name: 'Bob', salary: 65000, dept: 'Marketing'},
    {name: 'Carol', salary: 80000, dept: 'Engineering'}
];

// Native Dictionary access
let highEarners = employees
    .filter(fun(emp) { return emp.salary > 70000; })
    .map(fun(emp) { return emp.name; });

// Group by department (no external libs needed)
let byDept = employees.groupBy('dept');

// Direct VBA COM object integration
employees.forEach(fun(emp) {
    $1.Cells(emp.id, 1).Value = emp.name;
});

print(highEarners); // ['Alice', 'Carol']
ASF Advantage: Native VBA Dictionary operations. Built-in groupBy, direct COM object access. No marshalling overhead.

JS Object Conversion

JavaScript objects must be converted to/from VBA. Complex marshalling for COM objects. Additional libraries needed for advanced operations. 
// Convert VBA objects to JS
let vbaEmployees = getVBAEmployees();
let jsEmployees = convertToJSObjects(vbaEmployees);

// Process in JavaScript
let highEarners = jsEmployees
    .filter(emp => emp.salary > 70000)
    .map(emp => emp.name);

// Group by - need external library
import _ from 'lodash';
let byDept = _.groupBy(jsEmployees, 'dept');

// VBA COM access requires conversion
jsEmployees.forEach(emp => {
    let vbaRange = getVBARange(emp.id, 1);
    vbaRange.Value = emp.name;
});

console.log(highEarners); // ['Alice', 'Carol']
JavaScript Limitation: Conversion overhead, external dependencies, complex VBA COM marshalling, type safety issues.

String Manipulation

▼

ASF Native Strings

ASF strings are VBA Strings with JavaScript-like methods. Native VBA performance with modern ergonomics. 
let text = 'Hello, World! This is ASF.';

// Native VBA String with JS methods
let upper = text.toUpperCase();
let words = text.split(' ');
let filtered = words.filter(fun(w) { 
    return w.length > 4; 
});

// Template literals with VBA integration
let result = `Found ${filtered.length} words: ${filtered.join(', ')}`;

// Direct Excel integration
$1.Cells(1, 1).Value = result;

// Regex support
let pattern = /\b\w{5,}\b/g;
let longWords = text.match(pattern);

print(result);    // Found 2 words: 'Hello', 'World'
print(longWords); // ['Hello', 'World']
ASF Advantage: Native VBA String performance. Built-in regex engine. Template literals. Direct Excel/Word integration.

JS String Conversion

JavaScript string operations on VBA strings require conversion. Unicode and encoding issues. No direct VBA integration. 
// Convert VBA String to JS String
let vbaText = getVBAString();
let jsText = String(vbaText);

// Process in JavaScript
let upper = jsText.toUpperCase();
let words = jsText.split(' ');
let filtered = words.filter(w => w.length > 4);

// Template literals work but need conversion back
let result = `Found ${filtered.length} words: ${filtered.join(', ')}`;
let vbaResult = convertToVBAString(result);

// Excel integration requires VBA conversion
let excelRange = getExcelRange(1, 1);
excelRange.Value = vbaResult;

// Regex works but conversion overhead
let pattern = /\b\w{5,}\b/g;
let longWords = jsText.match(pattern);

console.log(result);    // "Found 2 words: Hello, World"
console.log(longWords); // ["Hello", "World"]
JavaScript Limitation: String conversion overhead. Unicode encoding issues. No direct Excel/VBA integration. Memory duplication.
