ASF — Advanced Scripting Framework for LibreOffice

A JavaScript-like scripting language implemented entirely in LibreOffice Basic. No external runtime, no Java, no Python: install one extension and run modern scripts from your macros, with direct access to Calc, Writer and every other UNO object.

GlobalScope.BasicLibraries.LoadLibrary "ASF"
Dim engine As Object: Set engine = ASF.LOhelper.NewASF()
engine.Run engine.Compile("return [1,2,3,4,5].filter(fun(x){ return x > 2 }).reduce(fun(a,x){ return a+x }, 0)")
MsgBox engine.OUTPUT_   ' => 12

Core features

Language

  • JavaScript-like syntax with lexical scoping
  • First-class functions and closures
  • ES6+ array methods: map, filter, reduce, find, forEach, splice, toSorted and more
  • Object and array literals with spread/rest operators, destructuring and template literals
  • Classes with inheritance (extends, super)
  • Built-in regular expression engine with lookarounds, backreferences, named groups and word boundaries
  • Module system with import/export

LibreOffice integration

  • Scripts call methods and properties of UNO objects passed to them: documents, sheets, cells, text, services
  • Variable injection from Basic into scripts, with Basic arrays turned into script arrays
  • More than 100 mathematical, statistical, financial and matrix functions through the VBA Expressions extension, with the @(...) syntax
  • Error containment and a runtime log for debugging

Architecture

  • Pure LibreOffice Basic: one Basic library named ASF
  • Sandboxed virtual machine with call stack tracing; access to UNO objects is off until you enable it
  • Generated from the same sources as the VBA edition for Microsoft Office, so both editions share the language and its fixes

Quick start

Step 1: Installation

  1. Download ASF.oxt and install it with Tools > Extension Manager > Add…, or run unopkg add ASF.oxt.
  2. Optional, for @(...) expressions: install the VBA Expressions extension, version 1.2.1 or later.
  3. Restart LibreOffice.

Requires LibreOffice 7.5 or later (tested on 24.2).

Step 2: Hello world

Load the library, create an engine through the LOhelper factories, compile and run. Basic has no Immediate window, so print() output is collected by LOhelper.GetOutput().

Sub HelloASF
    GlobalScope.BasicLibraries.LoadLibrary "ASF"
    Dim engine As Object
    Set engine = ASF.LOhelper.NewASF()
    engine.Run engine.Compile("print('Hello from ASF!')")
    MsgBox ASF.LOhelper.GetOutput()   ' => 'Hello from ASF!'
End Sub

Step 3: Real-world example

Scenario: filter and sum sales over $1000.

Sub ProcessSalesData
    GlobalScope.BasicLibraries.LoadLibrary "ASF"
    Dim engine As Object
    Set engine = ASF.LOhelper.NewASF()
    Dim script As String
    script = _
        "sales = [850, 1200, 950, 2500, 1100, 600];" & _
        "highValue = sales.filter(fun(x) { return x > 1000 });" & _
        "total = highValue.reduce(fun(sum, item) { return sum + item }, 0);" & _
        "return total;"
    engine.Run engine.Compile(script)
    MsgBox "High-value sales total: $" & engine.OUTPUT_   ' => $4800
End Sub

Data can also come from Basic. Arrays are injected as script arrays:

Sub InjectData
    GlobalScope.BasicLibraries.LoadLibrary "ASF"
    Dim engine As Object
    Set engine = ASF.LOhelper.NewASF()
    engine.InjectVariable "sales", Array(850, 1200, 950, 2500, 1100, 600)
    engine.Run engine.Compile("return sales.filter(fun(x) { return x > 1000 }).length;")
    MsgBox engine.OUTPUT_   ' => 3
End Sub

Step 4: Work with your documents

Turn on AppAccess and pass UNO objects as $1, $2… Here the script reads A1:A6 of the current Calc sheet, adds the values over 1000 and writes the result next to them:

Sub CalcTotals
    GlobalScope.BasicLibraries.LoadLibrary "ASF"
    Dim engine As Object
    Set engine = ASF.LOhelper.NewASF()
    engine.AppAccess = True
    Dim script As String
    script = _
        "let sheet = $1.getSheets().getByIndex(0);" & _
        "let total = 0;" & _
        "for (let r = 0, r < 6, r = r + 1) {" & _
        "    let v = sheet.getCellByPosition(0, r).Value;" & _
        "    if (v > 1000) { total = total + v };" & _
        "};" & _
        "sheet.getCellByPosition(1, 0).String = 'High-value total';" & _
        "sheet.getCellByPosition(2, 0).Value = total;" & _
        "return total;"
    engine.Run engine.Compile(script), ThisComponent
    MsgBox engine.OUTPUT_   ' => 4800 for 850, 1200, 950, 2500, 1100, 600 in A1:A6
End Sub

UNO methods and properties are found regardless of case, and typeof reports the object’s implementation name, for example object: <ScCellObj>.

Step 5: Regular expressions

Regex literals are written between backticks. Replacements support $1…$n:

Sub RegexDates
    GlobalScope.BasicLibraries.LoadLibrary "ASF"
    Dim engine As Object
    Set engine = ASF.LOhelper.NewASF()
    engine.Run engine.Compile("return 'Due 2026-11-30, paid 2026-12-02'.replace(`/(\d{4})-(\d{2})-(\d{2})/g`, '$3/$2/$1');")
    MsgBox engine.OUTPUT_   ' => Due 30/11/2026, paid 02/12/2026
End Sub

The engine is also available directly from Basic:

Sub RegexDirect
    GlobalScope.BasicLibraries.LoadLibrary "ASF"
    Dim re As Object
    Set re = ASF.LOhelper.NewRegex()
    re.Init "\b[A-Z]{3}-\d+\b"
    MsgBox re.Replace("Tickets ABC-12 and XYZ-345 are open", "#")   ' => Tickets # and # are open
End Sub

Step 6: VBA Expressions

With the VBA Expressions extension installed, @(...) evaluates its functions and sees the script’s variables. Matrices come back as arrays:

Sub VBAExpressionsDemo
    GlobalScope.BasicLibraries.LoadLibrary "ASF"
    Dim engine As Object
    Set engine = ASF.LOhelper.NewASF()
    engine.Run engine.Compile("x = 4; return @(sqr(x) + lgn(8;2));")
    MsgBox engine.OUTPUT_   ' => 5
    ASF.LOhelper.ClearOutput
    engine.Run engine.Compile( _
        "a = @({1;0;4}); b = @({1;1;6}); c = @({-3;0;-10});" & _
        "print(@(MROUND(LUDECOMP(ARRAY(a;b;c));4)));")
    MsgBox ASF.LOhelper.GetOutput()
    ' => [ [ -3, 0, -10 ], [ -0.3333, 1, 2.6667 ], [ -0.3333, 0, 0.6667 ] ]
End Sub

That’s it! You are now writing modern scripts in LibreOffice Basic.

More of the language

Classes

Sub ClassesDemo
    GlobalScope.BasicLibraries.LoadLibrary "ASF"
    Dim engine As Object
    Set engine = ASF.LOhelper.NewASF()
    engine.Run engine.Compile( _
        "class Shape {" & _
        "  field name = 'shape';" & _
        "  describe() { return this.name + ' with area ' + this.area(); };" & _
        "};" & _
        "class Square extends Shape {" & _
        "  field side = 1;" & _
        "  constructor(side) { this.name = 'square'; this.side = side; };" & _
        "  area() { return this.side * this.side; };" & _
        "};" & _
        "let [first, second] = [new Square(3), new Square(4)];" & _
        "return first.describe() + '; ' + second.describe();")
    MsgBox engine.OUTPUT_   ' => square with area 9; square with area 16
End Sub

Modules

A module exports what other scripts import. math.vas:

// Named exports
fun add(a, b) {
    return a + b;
};

fun multiply(a, b) {
    return a * b;
};

PI = 3.14159;

export { add, multiply, PI };

Set the folder relative imports start from with WorkingDir (or scwd() inside a script). Inside a module, its own relative imports start from the module’s folder, and ../ goes up one level:

Sub ModulesDemo
    GlobalScope.BasicLibraries.LoadLibrary "ASF"
    Dim engine As Object
    Set engine = ASF.LOhelper.NewASF()
    engine.WorkingDir = "/home/me/scripts"   ' folder that holds math.vas
    engine.Run engine.Compile( _
        "import { add, multiply, PI } from './math.vas';" & _
        "return `5 + 3 = ${add(5, 3)}, circle area: ${PI * multiply(5, 5)}`;")
    MsgBox engine.OUTPUT_   ' => 5 + 3 = 8, circle area: 78.53975
End Sub

Script and module files are read as UTF-8. engine.Execute(path) runs a script file directly.

When to use ASF

Good fits

  • Complex data processing: transformations of nested data, parsing, text processing with regular expressions
  • Dynamic business logic: rules stored as text and changed without editing macros
  • Functional programming: when map/filter/reduce read better than loops
  • Developer productivity: rapid prototyping with familiar JavaScript syntax

Use plain LibreOffice Basic for

  • Performance-critical code: tight loops over millions of items
  • Heavy document automation: long sequences of UNO calls with little logic between them
  • Type safety: when you want the Basic IDE to check types for you

Hybrid approach

Keep the logic in ASF and the bulk document work in Basic: inject the data, let the script decide, and write the result with UNO calls from Basic.

Common issues

SymptomFix
New ASF fails with “Invalid object reference”Basic resolves New when your module is compiled, before the library is loaded. Use ASF.LOhelper.NewASF(), NewRegex() or NewASFMap().
print() shows nothingRead the output with ASF.LOhelper.GetOutput(), or mirror it to a file with ASF.LOhelper.SetOutputFile(path).
Arrays built with Join break the scriptPass data with engine.InjectVariable "name", value instead of concatenating it into the source.
Calls on a document do nothingSet engine.AppAccess = True and pass the object to Run: engine.Run idx, ThisComponent, then use $1 in the script.
@(...) returns nothingInstall VBA Expressions 1.2.1 or later. Version 1.2.0 fails on LibreOffice 24.2 when the expression contains variables.

Differences from the Microsoft Office edition

  • The Excel object model (ThisWorkbook, Worksheet, Range) and the COM prototype libraries written for it do not apply; scripts use UNO objects instead.
  • User-defined functions for @(...) live in the UDFunctions module of the VBA Expressions library.
